Polypiler.Core.Frontends.Python converts, from CPython 3.14.8, https://www.python.org, under the
following licence:
- Syntax/PyLexer.cs: the tokenizer of Parser/lexer/lexer.c (tok_nextc, tok_backup, lookahead,
  verify_end_of_number, verify_identifier, tok_decimal_tail, tok_continuation_line, the prefix
  checks, tok_get_normal_mode, set_ftstring_expr, tok_get_fstring_mode) and the token kinds of
  Parser/token.c;
- Syntax/PySource.cs: the source preparation of Parser/tokenizer/string_tokenizer.c and helpers.c
  (translate_newlines, check_bom, get_coding_spec, get_normal_name, check_coding_spec, valid_utf8,
  ensure_utf8);
- Syntax/PyParser*.cs: the PEG grammar Grammar/python.gram rule by rule with its invalid_* rules,
  the parser runtime of Parser/pegen.c (memoization, the second pass, new_identifier, number_token,
  check_barry_as_flufl), the error reporting of Parser/pegen_errors.c and the actions of
  Parser/action_helpers.c (make_arguments, set_expr_context, get_expr_name, get_invalid_target,
  formatted_value, interpolation, joined_str, template_str, concatenate_strings,
  setup_full_format_spec, checked_future_import and the other helpers);
- Syntax/PyLiterals.cs: parsenumber of Parser/pegen.c and the string decoding of
  Parser/string_parser.c with the unicode_escape and bytes escape decoders of Objects/;
- Syntax/PyFuture.cs: Python/future.c;
- Syntax/PyCompileCheck.cs: the symbol table of Python/symtable.c (its visitors, add_def, check_name,
  the comprehension, annotation and type-parameter scopes, analyze_block and analyze_name) and the
  checks of Python/codegen.c (return, yield, await, break and continue with the frame-block stack,
  except*, starred targets, repeated keywords, patterns, static nesting, docstrings);
- Syntax/PyUnicode.cs: the name lookup of Modules/unicodedata.c (the Hangul syllable names and the
  derived name prefixes);
- Ast/PyAst.cs: the node classes and their fields of Parser/Python.asdl.

Summary of the changes: the C sources are restated in C# for the frontend's own node model
(Ast/PyNode); the tokenizer reads a byte array instead of a stream, a raised error is an exception
instead of an error indicator, left-recursive rules are grown as loops, and only the checks of the
symbol table and the code generator are kept, not the code they generate.

tests/fixtures/python/syntax holds source snippets taken from the tests of CPython's Lib/test, under
the same licence.
