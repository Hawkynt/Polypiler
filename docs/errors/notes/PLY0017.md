## Cause

The vector file `polypiler verify` compares with cannot be used: it is not JSON, it breaks the vector
file format of schema 1 (a missing `fixture` or `provenance`, an unknown property, an input or
expected value that is not the image of its signature), or its call signature has a parameter or a
result the JavaScript driver cannot pass: an `out` or `inout` parameter, or a type other than an
integer, `bool`, `f32`, `f64`, `bytes`, `utf8` and `utf16`. The reason names which.

## Example

```text
$ polypiler verify generated/adler32 --against broken.json
polypiler: error PLY0017: 'broken.json' holds no test vectors: not valid JSON: Expected depth to be zero at the end of the JSON payload. There is an open JSON object or array that should be closed. LineNumber: 1 | BytePositionInLine: 0.
```

## What to do

Write the vector file as `spec/schemas/vectors.schema.json` and `docs/cli/verify.md` describe: every
input and expected value as the image of the type its signature declares. The expected values are
read-only input of the verification; fix the file, not the values, and never record values Polypiler
produced (that is `PLY0063`).
