## Cause

The diagnostics registry `spec/diagnostics.yaml` breaks a rule of ADR 0003: a code is malformed,
listed twice, out of ascending order or outside the block of its area; an error lacks its exit code
or a warning carries one; a property is unknown, missing or of the wrong kind; or the file is not
YAML at all. Every command that reads the registry refuses it and writes nothing.

## Example

```text
$ polypiler-tooling diagnostics validate
spec/diagnostics.yaml(214,5): error PLY0045: duplicate code PLY0030
```

## What to do

Open the registry at the line and column the message names and correct the entry: give a new
diagnostic the next free code of its area's block, keep the list in ascending order and give every
error an `exit`. Run `polypiler-tooling diagnostics validate` until it reports `0 problems`.
