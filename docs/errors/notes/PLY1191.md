## Cause

`node --check` of a `.js`, `.mjs` or `.cjs` file of the input failed: the locked node cannot parse
it. The message names the file as the input names it, the line node reports and the `SyntaxError`
text.

## Example

```text
error PLY0030: target build failed: 'node --check broken.js' exited with 1
error PLY1191: node rejected the input: broken.js:2: SyntaxError: Unexpected token ';'
```

## What to do

Fix the source at the line given. JavaScript runs as written: the runner never transpiles, so
syntax newer than the locked node accepts is rejected here.
