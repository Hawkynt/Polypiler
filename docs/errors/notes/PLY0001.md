## Cause

Polypiler met an exception that nothing in it anticipated. This is a defect of Polypiler, not of the
input: whatever else the run reported, the exit code is 70.

## Example

```text
$ polypiler translate Crc32.cs --from csharp --to javascript --output out
error PLY0001: internal compiler error: System.InvalidOperationException: Sequence contains no elements
```

## What to do

Report the defect with the command line, the input file and the complete message. Until it is
fixed, try to narrow the input down to the construct that triggers it and leave that construct out.
