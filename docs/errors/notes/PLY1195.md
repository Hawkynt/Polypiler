## Cause

The JavaScript driver and the runner could not exchange the calls: the program has no entry module
(no `package.json` entry, no `index.mjs`, `index.cjs` or `index.js`, and not exactly one JavaScript
file), the driver read an input image it could not decode, the function under test wrote to
standard output, which carries the driver's answers, or the driver printed a line that is neither
an output image nor a trap line, or another number of lines than calls.

## Example

```text
error PLY1195: call 1: the function under test wrote to standard output
```

## What to do

Keep output of the function under test off standard output (`console.error` writes to standard
error), name the entry module in `package.json`, and give each vector an input image that fits the
signature.
