## Cause

`dotnet build` of a fixture or of generated C# failed in the C# compiler. The build runs with
`TreatWarningsAsErrors`, so a warning such as an unused local variable (`CS0168`, `CS0219`) fails it
too. The message lists every `CS` error the build printed, with the file, line and column.

## Example

```text
error PLY0030: target build failed: 'dotnet-sdk build Driver.csproj -c Release -o out …' exited with 1
error PLY1091: the C# compiler rejected the input: Fixture.cs(1,49): CS0029: Cannot implicitly convert type 'string' to 'int'
```

## What to do

Fix the source at the location given. An error located in `Driver.cs`, the generated driver, is
reported as `PLY1095` instead: the signature does not fit the declaration.
