## Cause

A document that is generated from a specification no longer matches what the specification
produces: under `--check` a page differs, is missing or exists for no registered code. The same
code refuses a hand-written note of `docs/errors/notes` that names no registered code or has a
section other than `## Cause`, `## Example` and `## What to do`.

## Example

```text
$ polypiler-tooling report errors --check
polypiler-tooling: error PLY0091: generated document out of date: 'docs/errors/PLY0004.md' differs
polypiler-tooling: error PLY0091: generated document out of date: 'docs/errors/README.md' differs
```

## What to do

Regenerate the documents with `polypiler-tooling report errors` and commit the result together with
the change of `spec/diagnostics.yaml` that caused it; never edit a generated page by hand. For a
refused note, rename it after a registered code or move its text into one of the three sections.
