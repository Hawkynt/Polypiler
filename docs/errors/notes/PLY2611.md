## Cause

The Visual Basic .NET source uses a construct the frontend does not lower, named in the message: a
type (`Decimal`, `Date`, `Object`, a class, an array of several dimensions or of arrays), a statement
(`GoTo`, `On Error`, `Exit Try`, a `Static` local, an `Exit` or `Continue` of a loop around the
innermost one), a parameter (`ByRef` that the procedure assigns, `ParamArray`), a member of a module or
a structure other than fields and procedures, a call of a function of the runtime it does not import
(`Left`, `Mid`, `InStr`, `Format`, …), a conversion from a string to a number, or a comparison of
strings under `Option Compare Text`.

## Example

```text
$ polypiler translate Report.vb --from visualbasic --to csharp --output out
Report.vb(4,9): error PLY2611: 'GoTo' is not supported by the Visual Basic .NET frontend
```

for

```vb
Public Module Report
    Public Function F() As Integer
        GoTo Done
Done:
        Return 1
    End Function
End Module
```

## What to do

Write the construct in the subset the [frontend](../../architecture/VISUALBASIC-FRONTEND.md#visual-basic-net)
lists: a structured loop or `If` for a `GoTo`, `Try`/`Catch` for `On Error`, a `Function` result for an
assigned `ByRef` parameter, `.Substring` for `Mid`, `Option Compare Binary` for comparisons of strings.
