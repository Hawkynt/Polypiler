The conversions round to nearest only: the code for the other rounding modes, the floating-point
exception flags and errno is left out. Where the result differs from upstream:

  - Hypot and HypotF return +infinity when one operand is infinite and the other is a signalling
    NaN, as IEEE 754-2019 §9.2.1 requires for any NaN; upstream returns a NaN for a signalling one.
  - ReciprocalSqrt and ReciprocalSqrtF return +infinity for -0, as IEEE 754-2019 §9.2.1 requires;
    upstream returns -infinity.
  - CbrtF leaves out the final adjustment of results close to an exact root, which no binary32
    input reaches when rounding to nearest.
